Build — this site & the stack behind it

Honestly, this whole website came together with the help of Claude Code. I didn't want some drag-and-drop template that looks like everyone else's, so I basically sat down, described the vibe I was going for, and kept iterating until it actually felt like me. I'd tweak a color, rewrite a paragraph, move a section around, and just keep going until each page felt right.

The process was equal parts designing and problem solving, which is probably why I loved it so much. I'd get an idea in my head, like a back button that fades as you scroll or a gaming page that reads like a little journey, and then work through it piece by piece until it clicked. A lot of trial and error, a lot of "wait, can we make it do this instead," and slowly it turned into the site you're looking at now.

If it isn't obvious by now, I'm genuinely passionate about AI, coding, and pretty much every kind of technology and software out there. Building this was just a fun excuse to play with tools like Claude Code and see how far I could push an idea. I'm really excited to keep learning, keep building, and see what I can create as this stuff keeps evolving.
