--- layout: default --- {%- assign p = site.data.profile -%} {%- comment -%} LAYOUT CHOICE — "flows into the next section" over a locked full-viewport hero. A 100vh centred hero is the template default (trivial to build, generic). A hero sized to its content that deliberately FLOWS — an asymmetric masthead grid, an identity "spec sheet", and a scroll cue — is harder to tune by hand and reads more editorial/premium, while improving usability: it invites the scroll instead of walling off a screen. Type wins; the background is a masked hairline blueprint grid, never a glow. Identity facets are inlined here for review; they can move to profile.yml later. {%- endcomment -%}

Hi, my name is {%- comment -%} The name is split per letter so it can cascade in on load. `--ci` is a running index across every word, so the stagger reads as one continuous left-to-right sweep rather than restarting on each line. The real name is carried by a visually-hidden span and the letters are aria-hidden, so a screen reader announces "Kevin Liu" instead of spelling it out. (A plain aria-label on this span would not be reliably exposed — it has no role.) {%- endcomment -%} {{ p.name }} {%- assign nameparts = p.name | split: " " -%} {%- assign ci = 0 -%} {%- for part in nameparts -%} {%- assign chars = part | split: "" -%} {%- for ch in chars -%} {{ ch }} {%- assign ci = ci | plus: 1 -%} {%- endfor -%} {%- endfor -%} and welcome to my website!
